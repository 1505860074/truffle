# Truffle 开发路线图

- 本文档描述**分阶段交付计划**与每阶段验收标准。
- 体例：按里程碑（M0/M1/…）组织，每个里程碑包含「目标 / 交付物 / 验收标准 / 预估工时」。
- 约定：完成一个里程碑后勾选并同步更新「当前进度」。
- 禁忌：不要把未确认的长期功能写成承诺；不确定项标注「待定」。

## M0 · 脚手架（本次交付）

- 目标：建立仓库、目录、依赖、可运行的空壳。
- 交付物：架构文档、路线图、代码骨架、git 仓库。
- 验收：`python -m truffle` 能打开窗口（依赖装好后）。

## M1 · 核心闭环（优先级最高）

- 目标：跑通「自然语言 → 大模型 → 调用工具 → 画布更新」。
- 交付物：
  - `ImageDocument` 撤销/重做与打开/保存
  - OpenAI 兼容 LLM 客户端 + 编排器（tool calling 循环）
  - 工具注册表 + `BaseTool` 抽象
  - 至少 2 个真实可用工具：**磨皮**、**美白**
  - 对话面板 + 图像画布 + 设置对话框（填 API Key）
- 验收：配置 API Key 后输入「帮我把皮肤磨光滑一点」，画布出现磨皮效果，可撤销。
- 预估：3~5 天。

## M2 · 人像 / 体型修饰工具集（业务核心）

- 目标：覆盖女性用户高频修饰诉求。
- 交付物（工具清单）：
  - 磨皮 / 美白（M1 已有则增强）
  - **瘦脸**（人脸关键点 + 局部形变）
  - **大眼**
  - **瘦身 / 调整体型**（身体区域局部形变）
  - **祛痘祛斑**（斑点检测 + 修补）
  - 牙齿美白、去黑眼圈（选做）
- 验收：一张人像照片可用自然语言组合调用以上工具，效果自然、无明显变形伪影。
- 预估：1~2 周。

## M3 · 体验打磨

- 目标：达到「非专业女性用户可直接上手」的水准。
- 交付物：
  - 前后对比视图（原图/现图滑块）
  - 一键预设（自然 / 日常 / 精致）
  - 中文友好提示与错误引导
  - PyInstaller 打包为 Windows exe
- 验收：双击 exe 可运行，无需命令行。
- 预估：1 周。

## M4 · 视频修饰

- 目标：把静态工具复用到视频。
- 交付物：抽帧、人脸跟踪平滑、逐帧处理、音视频重编码。
- 验收：一段 10 秒短视频可完成磨皮/瘦脸且无闪烁。
- 预估：2~3 周。

## 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 6GB 显存限制重模型 | 高质量换脸/超分受限 | 优先传统算法，重模型按需加载，用半精度/分块 |
| 局部形变效果生硬 | 瘦脸/瘦身出现伪影 | 高斯权重位移场 + 边缘羽化，参数保守 |
| LLM 参数幻觉 | 调用工具时传非法参数 | 工具侧参数校验 + 夹紧到合法区间 + 反馈给模型 |
| 大模型 API 不稳定 | 无法理解需求 | 支持多 base_url 切换；核心工具可手动面板兜底 |
